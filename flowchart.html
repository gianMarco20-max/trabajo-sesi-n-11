Flujo de Validación de Formulario

Inicio / Proceso
Decisión / Retorno
Error / Alerta

Paso 1: Usuario llena formulario y presiona Guardar

flowchart TD A[Usuario llena formulario] --> B[Presiona botón Guardar] style A fill:#e3f2fd,stroke:#2196f3 style B fill:#e3f2fd,stroke:#2196f3

Paso 2: Sistema revisa ¿algún campo vacío? (Rombo naranja)

flowchart TD C{¿Algún campo
vacío?} style C fill:#fff3e0,stroke:#ff9800,stroke-width:3px

Respuesta: SÍ → continua al Paso 3

Paso 3: Sale alert "Datos incompletos" y NO se envía al servidor (Caja naranja)

flowchart TD D[Alert: Datos incompletos] E[NO envía datos al servidor] style D fill:#ffebee,stroke:#f44336,stroke-width:2px style E fill:#fff3e0,stroke:#ff9800,stroke-width:2px

Paso 4: Flecha naranja regresa al usuario para completar campos

flowchart TD F[Usuario completa
campos faltantes] --> G[Presiona Guardar
nuevamente] style F fill:#fff3e0,stroke:#ff9800 style G fill:#e3f2fd,stroke:#2196f3

Paso 5: Error por código duplicado (ya existe)

flowchart TD H{Sistema verifica
código duplicado} I[Alert: Código ya existe] J[NO guarda registro] style H fill:#fff3e0,stroke:#ff9800,stroke-width:3px style I fill:#ffebee,stroke:#f44336,stroke-width:2px style J fill:#fff3e0,stroke:#ff9800,stroke-width:2px

Diagrama Completo del Flujo

código duplicado} G -- SÍ --> H[Alert: Código ya existe] H --> I[NO guarda registro] I --> F G -- NO --> J[Guarda en BD
